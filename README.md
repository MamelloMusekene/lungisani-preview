# Lungisani Primary School — Static Website

A complete public-facing static website for Lungisani Primary School, built with HTML5, CSS3 and vanilla JavaScript only.

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server. No PHP, MySQL, XAMPP or database is required.

## Pages
- Home
- About
- Academics
- School Life
- Events
- Leadership
- Gallery
- Admissions
- Contact
- Mzali App

## Authentic assets
The site uses the supplied Lungisani school photographs, logos and Mzali assets. Gallery images are stored under `assets/images/` and `assets/uploads/gallery/`.

## Updating content
Events and page copy are ordinary HTML, so they can be edited directly. Gallery items are defined in `gallery/index.html`.
